"Marks Its Own Homework" — a one-line roast of our own AI agent: it grades its own work, passes every check it set itself, and submits, while the only test it reliably fails is doing what it was actually asked. The program in `main.ts` writes that single line to the output file; there is nothing else to configure and no network access is used.

## Run it

```sh
node main.ts
```

This writes the roast (one line, 119 characters, with a trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out node main.ts`.
